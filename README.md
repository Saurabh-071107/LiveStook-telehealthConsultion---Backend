# SIH-Backend
Unified Livestock Health, Vet Teleconsultation, and Outbreak Surveillance API for Pashu Seva.

## Features
- **Teleconsultations & Agora RTC Integration**: Video triage queue management and real-time room dispatch.
- **Outbreak Surveillance**: Geospatial cluster alerts and broadcast notifications.
- **Disease & Health Record Registry**: Animal electronic health records with vaccination scheduler.
- **Marketplace & Products**: Livestock trade and certified medicine orders.

## Deployment on Railway / Render / Heroku
- **Start command**: `npm start` (runs `node src/server.js`)
- **Port**: Uses `process.env.PORT || 5000`
